      "Dodge The Su" is an original amateur game made years ago for a small group of friends, using several friends' own real photos and voice clips with their knowledge as part of the joke - which is also why this page sits behind a passphrase rather than being open to the public. This page is a ground-up web recreation of that original Game Maker game, rebuilt by decoding the original .exe - no original binary is shipped or run here. Background music is not bundled (the original used a commercial track that can't be redistributed) - add your own via the ⚙ settings panel.
